How to Book the Meeting Rooms:
You can make bookings via Outlook.  

 

Please make sure you have the Zoom app and the Outlook app downloaded on your laptop/phone to be able to utilise these rooms and make bookings. You will need to login with your UniMelb credentials for access. 

 

To make a booking, first create an event on your Outlook account using the Calendar tab.


Create an event through Outlook calendar
To book the room, you will need to set the location as the room's location. The room number is at the end of the location. 

The location code for the Capstone Meeting Rooms are: 

PAR-193-2-205
