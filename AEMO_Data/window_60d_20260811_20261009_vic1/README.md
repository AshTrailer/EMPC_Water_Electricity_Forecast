## 三、时区口径

全部时间戳是 NEM 时间(AEST,UTC+10,全年不随夏令时偏移),文件里没有时区后缀。按 UTC+10 直接解释,不要叠加本机夏令时。

## 四、跨度坐标怎么和官方对齐

官方给的是一串目标时刻,不是等间距的提前量:

- P5MIN:发布后第 0 到 55 分钟,每 5 分钟一个点,共 12 个。
- PREDISPATCH:发布时刻起每 30 分钟一个点,直到当日结束之后的 04:00,提前量在 15.5 到 39.0 小时之间浮动。
- PD7DAY:每 30 分钟一个点,直到 183 小时。

本项目的图集按**累计提前量的分钟数**建跨度轴,与官方对齐后是:

| 段 | 跨度列 | 提前量 |
|---|---|---|
| 前 12 列 | 5 分钟一档 | 5 至 60 分钟 |
| 之后 364 列 | 30 分钟一档 | 90 分钟至 183 小时 |
| 合计 | **376 列** | |

用这个轴,每个 (时刻, 跨度) 格子上的官方值都能逐点对上,不需要插值。
