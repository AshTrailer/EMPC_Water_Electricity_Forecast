## 2. 统一符号系统

### 2.1 时间与索引

| 符号 | 含义 | 类型与定义域 | 单位 |
|---|---|---|---|
| `k` | 流上的样本序号 | 整数,`1..N` | 无 |
| `N` | 样本总数 | 整数 | 无 |
| `t_k` | 第 `k` 个样本的 NEM 时间戳 | 时间 | NEM 时间,UTC+10,无夏令时 |
| `n_s` | 一天的槽位数,固定 288 | 常数 | 无 |
| `s(k)` | 样本 `k` 的日内槽位 | 整数,`1..288` | 无 |
| `d(k)` | 样本 `k` 所在日 | 整数 | 无 |
| `h` | 预测跨度,以 5 分钟为一步 | 整数,`1..288` | 步 |
| `D` | 目标日,即预测点所在的那一天 | 整数 | 无 |
| `u(k,h)` | 跨度为 `h` 的目标槽位 | 整数,`1..288` | 无 |
| `H` | 预测跨度上限,一次预测的点数 | 整数,默认 288 | 无 |

槽位约定:`s = 1` 对应 00:05,`s = 288` 对应 24:00。时间戳是**区间结束**时刻。
口径是"先吃进 `y(k)` 再发布",所以跨度 `h = 1` 指的是最新观测的**下一个**点。目标槽位公式:

```
u(k,h) = mod( s(k) - 1 + h, n_s ) + 1
```

验证:原点在槽位 288 时 `u(k,1) = 1`,即次日 00:05;原点在槽位 1 时 `u(k,288) = 1`,即次日 00:05。

跨到次日用未折叠序号判定:

```
dayAhead(k,h) = floor( ( s(k) - 1 + h ) / n_s )      取值为 0 或 1
```

### 2.2 数据与预处理

| 符号 | 含义 | 类型与定义域 | 单位 |
|---|---|---|---|
| `y(k)` | 原始区域参考价 RRP | 实数 | $/MWh |
| `y_c(k)` | 钳位后的价格 | 实数 | $/MWh |
| `q₁(d)` `q₉₉(d)` | 第 `d` 日的钳位阈值 | 实数 | $/MWh |
| `P_d(k)` | 总需求 | 实数 | MW |
| `x(k)` | 外生变量向量 | 实数向量 | 见 2.7 |

功率量一律用 `P` 打头,把 `D` 留给 2.1 的目标日。

钳位定义:阈值取自**原始价**在过去 30 个完整日的全局 1 分位与 99 分位,每日重算一次。

```
q₁(d), q₉₉(d) = prctile( { y(j) : j 属于 d 之前 30 个完整日 }, [1, 99] )
y_c(k) = clip( y(k), q₁(d(k)), q₉₉(d(k)) )
```

**模型状态在原始价上训练,评分在钳位价上。** 这条口径不能混。

### 2.3 模板与残差

| 符号 | 含义 | 类型与定义域 | 单位 |
|---|---|---|---|
| `T(s)` | 28 天滚动日内模板 | 实数,`288 × 1` | $/MWh |
| `T_w(s)` | `w` 天滚动日内模板 | 实数,`288 × 1` | $/MWh |
| `W` | 多窗口集合,默认 `{7, 28, 56, 112}` | 整数集合 | 天 |
| `T_mw(s)` | 多窗口模板,`W` 上算术平均 | 实数,`288 × 1` | $/MWh |
| `L̄` | 模板自身的日均水平 | 实数 | $/MWh |
| `L(d)` | 第 `d` 日的实际日均价 | 实数 | $/MWh |
| `L̂(D)` | 目标日均价的估计 | 实数 | $/MWh |
| `r(k)` | 相对模板的残差 | 实数 | $/MWh |
| `Δy(k)` | 一阶差分 | 实数 | $/MWh |
| `k_s` | 槽位 `s` 至今见过的样本数 | 整数 | 无 |

定义:

```
T(s)     = ( 1 / min(k_s, 28) ) · Σ_{i=1..min(k_s,28)} y_s^{(i)}
           其中 k_s 是槽位 s 至今见过的样本数,y_s^{(i)} 是最近的那些
T_mw(s)  = ( 1 / |W| ) · Σ_{w 属于 W} T_w(s)
L̄        = ( 1 / n_s ) · Σ_{s=1..n_s} T(s)
r(k)     = y(k) - T_{k-1}( s(k) )
Δy(k)    = y(k) - y(k-1)
```

**残差的关键点:`r(k)` 用的是槽位 `s(k)` 更新之前的模板值 `T_{k−1}`。**
顺序错了会让 RLS 的自适应目标与残差定义不一致。

### 2.4 自适应量

| 符号 | 含义 | 类型与定义域 | 单位 |
|---|---|---|---|
| `φ` | 残差自回归系数 | 实数向量,长度 `p` | 无 |
| `p` | AR 阶数,现为 4 | 整数 | 无 |
| `λ` | RLS 遗忘因子,现为 0.98 | 实数,`0 < λ ≤ 1` | 无 |
| `δ` | RLS 初始协方差尺度,现为 100 | 实数 | 无 |
| `P_rls` | RLS 协方差矩阵或标量 | 实数 | 见下 |
| `D_h` | 直接多步回归的系数矩阵,第 `h` 行对应跨度 `h` | 实数,`288 × (p+1)` | 无 |
| `θ(s)` | Theta-y 的逐槽增益 | 实数,`288 × 1` | 无 |
| `π(s)` | 凸混合权重 | 实数,`288 × 1`,取值 `[0,1]` | 无 |
| `ρ(k)` | 当日已观测槽位占比,取值 `[0,1]` | 实数 | 无 |
| `b₁` | 水平递归的昨日权重 | 实数 | 无 |
| `c` | 水平递归的截距 | 实数 | $/MWh |
| `a_h` `b_h` `c_h` | Anchor-mix 第 `h` 个跨度的系数 | 实数 | 无 / 无 / $/MWh |
| `φ_hj` `ψ_hj` | Anchor-mix 第 `h` 跨度第 `j` 个滞后的系数 | 实数 | 无 |
| `η` | Anchor-mix 滞后系数的岭罚权重,0 表示不罚 | 实数,`η ≥ 0` | 无 |

**`η` 与 2.6 节的收缩系数 `ε` 不是一回事。** `η` 收缩的是 Anchor-mix 的滞后系数,`ε` 收缩的是组合权重的误差协方差。

**本节的 `P_rls` 是 RLS 的协方差,2.9 节的 `P_k` 是卡尔曼的协方差,两者不是一回事。**
**`π(s)` 是同一预测器内部的凸混合权重,`w_m` 是不同预测器之间的组合权重,不要混用。**

向量 RLS 更新,`u` 是回归量,`z` 是被解释量:

```
G_rls = P_rls u / ( λ + uᵀ P_rls u )
ξ     = z - uᵀ θ
θ     = θ + G_rls ξ
P_rls = ( P_rls - G_rls uᵀ P_rls ) / λ,  然后 P_rls ← (P_rls + P_rlsᵀ)/2,再按迹截断 trace(P_rls) ≤ 10⁸
```

标量 RLS 是 `u` 退化为标量的特例:

```
G_rls = P_rls u / ( λ + P_rls u² ),   θ = θ + G_rls ( z - θ u ),   P_rls = ( 1 - G_rls u ) P_rls / λ
```

### 2.5 预测与误差

| 符号 | 含义 | 类型与定义域 | 单位 |
|---|---|---|---|
| `ŷ(k+h\|k)` | 在 `k` 时刻对 `k+h` 的预测 | 实数 | $/MWh |
| `r̂(k+h\|k)` | 残差预测 | 实数 | $/MWh |
| `e(k,h)` | 钳位后的预测误差 | 实数 | $/MWh |
| `E(s,h,d,m)` | 误差图集,第 `m` 个模型 | 实数,`288 × 288 × D × M` | $/MWh |
| `R(s,h,m)` | 图集上的 RMSE 面 | 实数,`288 × 288` | $/MWh |
| `R̄(m)` | 整图 pooled RMSE | 实数 | $/MWh |

```
e(k,h)   = y_c(k+h) - clip( ŷ(k+h|k), q₁(d(k+h)), q₉₉(d(k+h)) )     仅当 k+h 落在评分窗口内
E(s,h,d,m) = e(k,h)   其中 k 满足 s(k+h)=s、d(k+h)=d、模型为 m
R(s,h,m) = sqrt( ( 1 / n_d ) Σ_{d} E(s,h,d,m)² )
R̄(m)     = sqrt( ( 1 / (n_s · n_s · n_d) ) Σ_{s,h,d} E(s,h,d,m)² )
```

`n_d` 是评分天数,现为 120。**每个格子有 `n_d` 个样本**,这是后面所有切片统计的自由度来源。

**凸组合的关键恒等式**,所有权重和方法都基于它:

```
若 f_c = Σ_m w_m f_m 且 Σ_m w_m = 1,则
e_c = y - f_c = Σ_m w_m ( y - f_m ) = Σ_m w_m e_m
```

也就是说,**凸组合的误差可以直接从各模型的误差图集算出来,不需要重新预测。**
这是 `run_ensemble_combos.m` 能在 3 分钟内试 17 种组合的原因。

## 3. 每个预测器的数学模型

记号:`T` 与 `T_mw` 见 2.3。所有预测都满足同一句口径:**先吃进 `y(k)`,再发布 `ŷ(k+h|k)`**。
每个符号的定义在 2.9 节之前都登记过,本节不重复,只对本模型特有的量补一句来源。

**幻灯片按 8.2 的第三条规矩,会在每个公式正下方把所有符号逐条列出来。本节是那些列表的来源。**

### M1 Persistence

```
ŷ(k+h|k) = y( u(k,h) 在前一日的对应样本 )
```

与跨度无关。它是所有其他模型必须打败的参照。

### M2 Rolling template

```
ŷ(k+h|k) = T( u(k,h) )
```

与跨度无关。零参数,承载全部跨日记忆。

### M3 Theta-y tracker

```
ŷ(k+h|k) = θ( u(k,h) ) · y_prev( u(k,h) )
```

`y_prev(s)` 是槽位 `s` 昨日的值。`θ(s)` 由标量 RLS 估计,先验 `θ₀ = 1`,此时退化为持续性。
每个槽位每天只更新一次。

### M4 T28 + AR(4) 迭代

残差自回归,系数冻结后递归:

```
r(k)      = y(k) - T_{k-1}( s(k) )
r̂(k+s|k)  = Σ_{j=1..p} φ_j · r̃(k+s-j)          s = 1..H
            其中 r̃ 在 s-j ≤ 0 时取真实残差,否则取自己的预测
ŷ(k+h|k)  = T( u(k,h) ) + r̂(k+h|k)
```

**这就是长期退化的机制**:`s > p` 之后每个输入都是预测值,递归按 `φ` 的谱半径衰减。
实测 `p = 4` 时它在 24 小时跨度上比裸模板还差 11.3%。

**阶数不是越大越好,而且 4 不是最优。** 120 天口径重测 p 从 1 到 48,工具是 `run_ar_order_sweep.m`:

| 跨度 | 最优 p | 该 p 的 RMSE | p = 4 的 RMSE |
|---|---|---|---|
| 5 分钟 | 3 | 10.478 | 10.568 |
| 30 分钟 | 5 | 16.752 | 16.820 |
| 1 小时 | 5 | 22.865 | 22.911 |
| 3 小时 | 2 | 37.960 | 38.107 |
| 6 小时 | 1 | 46.410 | 48.725 |
| 12 小时 | 1 | 49.132 | 54.201 |
| 24 小时 | 1 | 48.166 | 53.350 |

整图上从 p = 1 到 p = 48 的整图值见 `ar_sweep.mat`,**那一列只作运行指纹,不作判据**。
**整图上从 p = 1 的 46.83 单调变差到 p = 48 的 67.24,一路没有第二个极小值。**
机制与上面的退化是同一条:阶数越高递归衰减越慢,长跨度上把当前残差水平外推得越远。
残差没有长期记忆,**快速衰减才是对的**。
短跨度上有一个很浅的最优,落在 p 等于 3 到 5 之间,改善只有 1% 量级。

**结论:M4 应该用 p = 1,整图改善 7.9%。**
即使换到 p = 1,M4 的 46.83 仍然打不过 M8 的 38.14。
**AR 残差是短跨度工具,不是主力。**

**这一条也推翻了归档脚本的前提。** 旧扫描用的是纯 AR 加常数水平,p 只到 10,也没钳位;
它的结论不能直接搬到模板加 AR 的结构上。

**实现上有一处提速。** 递推 `r̂(s) = φᵀ [r̂(s-1); ...; r̂(s-p)]`,把最新 p 个残差当作后向初始输出,
就等价于一个 AR(p) 滤波器,一次 `filter` 调用替代 288 次循环。
两式在随机系数上逐点一致,`p = 4` 时偏差 2.8e-17。48 个 p 值因此能在半小时内跑完。

### M5 Carry-forward

```
ŷ(k+h|k) = y(k)
```

与跨度无关。短跨度上极强,长跨度上等于随机游走。

### M6 T28 + DMS(4) 直接多步

每个跨度单独做一次最小二乘,不递归:

```
ŷ(k+h|k) = D_h · [ 1, r(k), r(k-1), ..., r(k-p+1) ]ᵀ + T( u(k,h) )
```

`D_h` 每日在滚窗上重估一次,窗长 `n_fit` 天。第 `h` 行的训练样本是 `{ r(j+h) 与 r(j..j-p+1) }`。

### M7 CF + DMS(4)

与 M6 同构,但回归量换成差分 `Δy`,基准换成 `y(k)`:

```
ŷ(k+h|k) = y(k) + D'_h · [ 1, Δy(k), ..., Δy(k-p+1) ]ᵀ
```

### M8 Anchor-mix

**当前单模型冠军。** 每个跨度独立最小二乘:

```
ŷ(k+h|k) = c_h + a_h · y(k) + b_h · T( u(k,h) )
           + Σ_{j=1..p} φ_hj · r(k-j+1)
           + Σ_{j=1..p} ψ_hj · Δy(k-j+1)
```

三个锚同时在场:最新价 `y(k)`、目标槽位的模板 `T`、以及短滞后修正。
系数每日重估,窗长 `n_fit` 天。

两个可选约束,代码里已实现但**调用时没打开**:

```
convex:   b_h = 1 - a_h,  a_h ← clip(a_h, 0, 1)
eta:      在滞后系数上加岭罚,权重取 mean(列能量) 的一个比例
```

参数名是 `convex` 与 `eta`,登记在 2.4。

**注意:现在跑的是无正则最小二乘,拟合时报秩亏(rank 10 对 12 列)。**

### M9 T28 + 水平偏置

```
L̂(d)     = c + b₁ · L(d-1)                       回归得到
L̂(d+1)   = c + b₁ · L̂(d)
ŷ(k+h|k) = T( u(k,h) ) + ( L̂(D) - L̄ )
```

`L(d−1)` 是原点的日之前最后一个**完整日**的均值。系数每日在滚窗上重估,窗长 `n_lvl` 天。
实测 `b₁` 的日均是 0.531。

### M11 MW + 水平偏置

### M12 MW + 运行状态水平

M11 的改进版。偏置的当日部分换成运行均值:

```
ρ(k)      = ( 当日已观测槽位数 ) / n_s
L̂(D=当日) = ρ(k) · ( 当日运行均值 ) + ( 1 - ρ(k) ) · ( c + b₁ · L(d-1) )
L̂(D=次日) = c + b₁ · L̂(当日)
ŷ(k+h|k)  = T_mw( u(k,h) ) + ( L̂(D) - mean_s T_mw(s) )
```

**混合权重就是观测比例本身,不需要额外拟合。** 观测比例记作 `ρ(k)`,登记在 2.4。
这一条把 24 小时跨度的水平误差从 34.60 压到 7.62 至 26.36。

### M13 Kalman 谐波状态空间,已收编

`Kalman_predictor`。结构与其他模型完全不同。

```
状态      ξ_k = [ μ_k, α_{1,k}, β_{1,k}, ..., α_{J,k}, β_{J,k}, r_k, ..., r_{k-p+1} ]ᵀ
转移      ξ_k = A ξ_{k-1} + w_k,     w_k ~ N(0, Q_w)
观测      y(k) = C_k ξ_k + v_k,      v_k ~ N(0, R_v)
预言      ξ̂_{k|k-1} = A ξ̂_{k-1|k-1}
更新      ξ̂_{k|k}   = ξ̂_{k|k-1} + K_k ( y(k) - C_k ξ̂_{k|k-1} )
          K_k = P_{k|k-1} C_kᵀ ( C_k P_{k|k-1} C_kᵀ + R_v )^{-1}
H 步预测  ŷ(k+h|k) = C_{k+h} A^h ξ̂_{k|k}
```

符号见 2.9。`C_k` 由 `make_harmonic_C.m` 按目标槽位构造,含 `J = 3` 个谐波对。
`A` 由 `build_harmonic_ss_model.m` 构造,状态量是水平、各次谐波振幅、以及一个 `p = 4` 阶残差块。
谐波块有一条解析性质:`A^h` 的谐波部分是旋转 `h·ω_j` 角,所以 `A^{n_s}` 的谐波块是单位阵,
24 小时预测与当前相位自洽。这条性质在代码里被当作正确性自检。

**落到 288 乘 288 图集时的实现。** 照上式在每个原点跑 288 步,要构造 1000 万次观测行,跑不完。
观测行与状态无关,只有跨度与目标槽位决定它,于是可以预计算 `G(h,s) = C_s A^h` 这一张表:

```
ŷ(k+h|k) = G( h, u(k,h) ) · ξ̂_{k|k}
```

这张表全测试期共用,占 7 MB,预测退化成一次长度 `1 + 2J + p = 11` 的内积。
**这是等价变形,不改任何数值。判据:与逐点实现 `kalman_predict_288.m` 对比,
四个原点上的最大偏差是 5.1e-13。**

谐波基在热身期上拟合一次,滤波状态与协方差在线递推。
**这是"固定基"口径;谐波基每日滚动重估是另一个变体,尚未测。**

实测整图 44.73。**5 分钟跨度上 10.10,是全表最好的一个**,M8 在那里是 10.17。
到 24 小时是 48.76,退化得比 M8 快。**它是短跨度专家,不是全能选手。**

### M14 EWMA 模板,已收编

`EWMA_Template_predictor`。与 M2 同构,但窗口换成指数加权:

```
T_e(s) = Σ_{i=0..n-1} ω_i · y^{(i)}(s) / Σ_i ω_i,    ω_i = (1 - α)^i
```

`i = 0` 是最新一天,`α = 0.15`。历史严格截断在权重降到 `min_weight = 0.01` 的那一天,
所以缓冲深度是 `K = floor( log(min_weight) / log(1-α) ) = 28` 天。
**这一条是与归档版的区别:纯递归 `T ← (1-α)T + αy` 有无限记忆,本实现会真的丢掉旧数据。**

收编时**去掉了按星期几分型那一维**,分类单独由 M18 承担,两个方向分开测。

实测整图 42.99,**与 M10 多窗口模板撞到同一位小数**。
两者都是平滑模板,逐跨度上互有胜负:M10 在 5 分钟上 43.09 对 43.16,M14 在 24 小时上 42.66 对 42.75。
**结论:加权方式与窗口长度这两个方向,在整图上打平;要分胜负必须看第 5 节的差值图。**

### M15 至 M17 移动平均与移动中值,已收编

`Smoothing_predictor`。三个变体,窗口都是 12 点,即 1 小时:

```
不平滑补偿   ŷ(k+h|k) = S(k)
延迟补偿     ŷ(k+h|k) = S(k) + ( (w-1)/2 + h ) · ( S(k) - S(k-1) )
```

`S(k)` 是窗口内的均值或中值。**延迟 `(w-1)/2 = 5.5` 步是解析的,写在状态里,不靠调参。**

三个变体的整图:

| 模型 | 整图 | 24 小时 |
|---|---|---|
| M15 移动平均 | 51.51 | 48.30 |
| M17 移动中值 | 51.59 | 48.30 |
| M16 移动平均加延迟补偿 | 86.38 | 94.54 |

**三条结论,都是负面的,写清楚为什么不留:**

1. **平滑过的序列不是预测。** 移动平均的整图 51.51,比裸持续性 48.27 还差。
   它就是把当天已有的水平往后平推,没有任何跨日记忆。
2. **中值比均值略差,差得不多。** 51.59 对 51.51。钳位已经在处理尖峰,中值的稳健性在这里没有额外价值。
3. **延迟补偿是灾难。** 86.38,是全部 18 个模型里最差的,24 小时上 94.54 已经超过信号标准差 48.77。
   原因是把 1 小时的斜率线性外推 288 步,外推误差按跨度线性增长。

**判据:三条都以"整图更差"的形式成立,所以三个都不进组合。
保留在图集里是为了让"平滑后再预测"这个想法有一组可引用的数字,不是为了凑数。**
这一条同时回答了归档里那两种滤波器的去向。

### M18 按星期几分型模板,已收编

`Day_Class_predictor`。用目标日所属的类别取模板:

```
T_c(s) = ( 1 / N_c ) Σ_{d 属于 W_c} y_d(s),    c 属于 {工作日, 周末}
```

窗口与 M2 一样是 28 天,所以**分类是它与 M2 之间唯一的区别**,这是一个受控对比。

**实测 43.82,比同窗口不分型的 M2 的 49.12 好 10.8%。**
这**推翻了**旧协议下的那个结论。旧测量说"按星期几分型比不分型差 3.4%",
那是在训练 1 月、测试 7 天的口径下测的,样本太少,周末只有 2 天,分型反而把样本切碎了。
120 天口径下每个类别有 17 个周末日与 86 个工作日日,分型的收益才显出来。

**这一条改进了报告的结论,不要再用旧的 3.4%。**

### M19 按跨度选 AR 阶数,第一版无效,要重做

动机来自 M4 的阶数扫描:最优阶数随跨度下降,30 分钟附近是 5,6 小时以上是 1。
把那张表直接用上不行,因为它是同一批 120 天上选出来的,等于用测试集调参。所以必须做成因果的。

```
候选集     P = {1, 2, 3, 5, 8}
每个候选一套独立的 RLS 状态
每个原点的候选预测   r̂_p = filter( 1, [1; -φ_p], 0, filtic(1, [1; -φ_p], r_hist(1:p)) )
跨度 h 的预测        ŷ(k+h|k) = T(u(k,h)) + r̂_{p*(h)}(h)
选择规则             p*(h) = argmin_p 过去最多 28 个完整日的平方误差
```

每个候选的 288 步预测是一次 `filter` 调用,所以五个候选几乎不增加成本。

**跑出来整图 49.27,比 M4 的 50.83 好,但比扫描给出的 p = 1 的 46.83 差。**
诊断把它暴露了:**在探针取的六个跨度上,规则 100% 选了 p = 1。**

**根因是选择用错了维度。** 累计的平方误差只按(目标槽位、候选、日)组织,**没有跨度这一维**,
所以 `min` 是在"对所有跨度求和"之后做的。它选出的是"每个目标槽位一个阶数",
不是"每个槽位与跨度各一个阶数"。聚合之后长跨度占主导,于是几乎全选 p = 1。

**这不是可以保留的近似,它没有回答原问题。要改的地方写清楚:**

1. 累计量改成(槽位、跨度、候选)三维,用按目标日的环形缓冲加滑动和,内存约 46 MB。
   不能直接存每天的全量,那是 288 乘 288 乘 120 乘 5。
2. 选择每天开始时做一次,窗口取最近 28 个完整目标日。落在窗口里的那天必须已经收齐,
   而目标日 `d-1` 的贡献在当天最后一个原点之前就全部到齐,所以窗口取到 `d-1` 是安全的。
3. 预测时按 `(u(h), h)` 取候选,不是只按 `h` 取。

**M19 现在这一列留在图集里只作中间结果,不要引用它的分数。**
下一次图集运行会把它换成正确的实现,同时修掉 PART 2 的稀释问题。
