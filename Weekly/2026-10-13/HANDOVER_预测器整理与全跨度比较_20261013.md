## 2. 统一符号系统

**这一节是符号的唯一定义。新符号必须在此登记后才能用。**
第 3 节与幻灯片会在每个公式正下方就地重复该页用到的符号,那是为了阅读方便。**登记只认这一节,重复处与本节不一致时以本节为准。**

### 2.1 时间与索引

| 符号 | 含义 | 类型与定义域 | 单位 |
|---|---|---|---|
| `k` | 流上的样本序号 | 整数,`1..N` | 无 |
| `N` | 样本总数 | 整数 | 无 |
| `t_k` | 第 `k` 个样本的 NEM 时间戳 | 时间 | NEM 时间,UTC+10,无夏令时 |
| `n_s` | 一天的槽位数,固定 288 | 常数 | 无 |
| `s(k)` | 样本 `k` 的日内槽位 | 整数,`1..288` | 无 |
| `d(k)` | 样本 `k` 所在日 | 整数 | 无 |
| `h` | 预测跨度,以 5 分钟为一步 | 整数,`1..288` | 步 |
| `D` | 目标日,即预测点所在的那一天 | 整数 | 无 |
| `u(k,h)` | 跨度为 `h` 的目标槽位 | 整数,`1..288` | 无 |
| `H` | 预测跨度上限,一次预测的点数 | 整数,默认 288 | 无 |

槽位约定:`s = 1` 对应 00:05,`s = 288` 对应 24:00。时间戳是**区间结束**时刻。
口径是"先吃进 `y(k)` 再发布",所以跨度 `h = 1` 指的是最新观测的**下一个**点。目标槽位公式:

```
u(k,h) = mod( s(k) - 1 + h, n_s ) + 1
```

验证:原点在槽位 288 时 `u(k,1) = 1`,即次日 00:05;原点在槽位 1 时 `u(k,288) = 1`,即次日 00:05。

跨到次日用未折叠序号判定:

```
dayAhead(k,h) = floor( ( s(k) - 1 + h ) / n_s )      取值为 0 或 1
```

### 2.2 数据与预处理

| 符号 | 含义 | 类型与定义域 | 单位 |
|---|---|---|---|
| `y(k)` | 原始区域参考价 RRP | 实数 | $/MWh |
| `y_c(k)` | 钳位后的价格 | 实数 | $/MWh |
| `q₁(d)` `q₉₉(d)` | 第 `d` 日的钳位阈值 | 实数 | $/MWh |
| `P_d(k)` | 总需求 | 实数 | MW |
| `x(k)` | 外生变量向量 | 实数向量 | 见 2.7 |

功率量一律用 `P` 打头,把 `D` 留给 2.1 的目标日。

钳位定义:阈值取自**原始价**在过去 30 个完整日的全局 1 分位与 99 分位,每日重算一次。

```
q₁(d), q₉₉(d) = prctile( { y(j) : j 属于 d 之前 30 个完整日 }, [1, 99] )
y_c(k) = clip( y(k), q₁(d(k)), q₉₉(d(k)) )
```

**模型状态在原始价上训练,评分在钳位价上。** 这条口径不能混。

### 2.3 模板与残差

| 符号 | 含义 | 类型与定义域 | 单位 |
|---|---|---|---|
| `T(s)` | 28 天滚动日内模板 | 实数,`288 × 1` | $/MWh |
| `T_w(s)` | `w` 天滚动日内模板 | 实数,`288 × 1` | $/MWh |
| `W` | 多窗口集合,默认 `{7, 28, 56, 112}` | 整数集合 | 天 |
| `T_mw(s)` | 多窗口模板,`W` 上算术平均 | 实数,`288 × 1` | $/MWh |
| `L̄` | 模板自身的日均水平 | 实数 | $/MWh |
| `L(d)` | 第 `d` 日的实际日均价 | 实数 | $/MWh |
| `L̂(D)` | 目标日均价的估计 | 实数 | $/MWh |
| `r(k)` | 相对模板的残差 | 实数 | $/MWh |
| `Δy(k)` | 一阶差分 | 实数 | $/MWh |
| `k_s` | 槽位 `s` 至今见过的样本数 | 整数 | 无 |

定义:

```
T(s)     = ( 1 / min(k_s, 28) ) · Σ_{i=1..min(k_s,28)} y_s^{(i)}
           其中 k_s 是槽位 s 至今见过的样本数,y_s^{(i)} 是最近的那些
T_mw(s)  = ( 1 / |W| ) · Σ_{w 属于 W} T_w(s)
L̄        = ( 1 / n_s ) · Σ_{s=1..n_s} T(s)
r(k)     = y(k) - T_{k-1}( s(k) )
Δy(k)    = y(k) - y(k-1)
```

**残差的关键点:`r(k)` 用的是槽位 `s(k)` 更新之前的模板值 `T_{k−1}`。**
顺序错了会让 RLS 的自适应目标与残差定义不一致。

### 2.4 自适应量

| 符号 | 含义 | 类型与定义域 | 单位 |
|---|---|---|---|
| `φ` | 残差自回归系数 | 实数向量,长度 `p` | 无 |
| `p` | AR 阶数,现为 4 | 整数 | 无 |
| `λ` | RLS 遗忘因子,现为 0.98 | 实数,`0 < λ ≤ 1` | 无 |
| `δ` | RLS 初始协方差尺度,现为 100 | 实数 | 无 |
| `P_rls` | RLS 协方差矩阵或标量 | 实数 | 见下 |
| `D_h` | 直接多步回归的系数矩阵,第 `h` 行对应跨度 `h` | 实数,`288 × (p+1)` | 无 |
| `θ(s)` | Theta-y 的逐槽增益 | 实数,`288 × 1` | 无 |
| `π(s)` | 凸混合权重 | 实数,`288 × 1`,取值 `[0,1]` | 无 |
| `ρ(k)` | 当日已观测槽位占比,取值 `[0,1]` | 实数 | 无 |
| `b₁` | 水平递归的昨日权重 | 实数 | 无 |
| `c` | 水平递归的截距 | 实数 | $/MWh |
| `a_h` `b_h` `c_h` | Anchor-mix 第 `h` 个跨度的系数 | 实数 | 无 / 无 / $/MWh |
| `φ_hj` `ψ_hj` | Anchor-mix 第 `h` 跨度第 `j` 个滞后的系数 | 实数 | 无 |
| `η` | Anchor-mix 滞后系数的岭罚权重,0 表示不罚 | 实数,`η ≥ 0` | 无 |

**`η` 与 2.6 节的收缩系数 `ε` 不是一回事。** `η` 收缩的是 Anchor-mix 的滞后系数,`ε` 收缩的是组合权重的误差协方差。

**本节的 `P_rls` 是 RLS 的协方差,2.9 节的 `P_k` 是卡尔曼的协方差,两者不是一回事。**
**`π(s)` 是同一预测器内部的凸混合权重,`w_m` 是不同预测器之间的组合权重,不要混用。**

向量 RLS 更新,`u` 是回归量,`z` 是被解释量:

```
G_rls = P_rls u / ( λ + uᵀ P_rls u )
ξ     = z - uᵀ θ
θ     = θ + G_rls ξ
P_rls = ( P_rls - G_rls uᵀ P_rls ) / λ,  然后 P_rls ← (P_rls + P_rlsᵀ)/2,再按迹截断 trace(P_rls) ≤ 10⁸
```

标量 RLS 是 `u` 退化为标量的特例:

```
G_rls = P_rls u / ( λ + P_rls u² ),   θ = θ + G_rls ( z - θ u ),   P_rls = ( 1 - G_rls u ) P_rls / λ
```

### 2.5 预测与误差

| 符号 | 含义 | 类型与定义域 | 单位 |
|---|---|---|---|
| `ŷ(k+h\|k)` | 在 `k` 时刻对 `k+h` 的预测 | 实数 | $/MWh |
| `r̂(k+h\|k)` | 残差预测 | 实数 | $/MWh |
| `e(k,h)` | 钳位后的预测误差 | 实数 | $/MWh |
| `E(s,h,d,m)` | 误差图集,第 `m` 个模型 | 实数,`288 × 288 × D × M` | $/MWh |
| `R(s,h,m)` | 图集上的 RMSE 面 | 实数,`288 × 288` | $/MWh |
| `R̄(m)` | 整图 pooled RMSE | 实数 | $/MWh |

```
e(k,h)   = y_c(k+h) - clip( ŷ(k+h|k), q₁(d(k+h)), q₉₉(d(k+h)) )     仅当 k+h 落在评分窗口内
E(s,h,d,m) = e(k,h)   其中 k 满足 s(k+h)=s、d(k+h)=d、模型为 m
R(s,h,m) = sqrt( ( 1 / n_d ) Σ_{d} E(s,h,d,m)² )
R̄(m)     = sqrt( ( 1 / (n_s · n_s · n_d) ) Σ_{s,h,d} E(s,h,d,m)² )
```

`n_d` 是评分天数,现为 120。**每个格子有 `n_d` 个样本**,这是后面所有切片统计的自由度来源。

### 2.6 组合与集成

| 符号 | 含义 | 类型与定义域 | 单位 |
|---|---|---|---|
| `M` | 模型总数 | 整数,现为 12 | 无 |
| `w_m` | 第 `m` 个模型的权重 | 实数,`Σ_m w_m = 1` | 无 |
| `ε` | 权重收缩系数,取 `[0,1]` | 实数 | 无 |
| `B` | 跨度分块宽度,默认 48 | 整数 | 步 |
| `K_sel` | 选择性等权保留的模型数 | 整数 | 无 |
| `n_w` | 权重拟合窗口,默认 28 | 整数 | 天 |

**凸组合的关键恒等式**,所有权重和方法都基于它:

```
若 f_c = Σ_m w_m f_m 且 Σ_m w_m = 1,则
e_c = y - f_c = Σ_m w_m ( y - f_m ) = Σ_m w_m e_m
```

也就是说,**凸组合的误差可以直接从各模型的误差图集算出来,不需要重新预测。**
这是 `run_ensemble_combos.m` 能在 3 分钟内试 17 种组合的原因。

## 3. 每个预测器的数学模型

记号:`T` 与 `T_mw` 见 2.3。所有预测都满足同一句口径:**先吃进 `y(k)`,再发布 `ŷ(k+h|k)`**。
每个符号的定义在 2.9 节之前都登记过,本节不重复,只对本模型特有的量补一句来源。

**幻灯片按 8.2 的第三条规矩,会在每个公式正下方把所有符号逐条列出来。本节是那些列表的来源。**

### M1 Persistence

```
ŷ(k+h|k) = y( u(k,h) 在前一日的对应样本 )
```

与跨度无关。它是所有其他模型必须打败的参照。

### M2 Rolling template

```
ŷ(k+h|k) = T( u(k,h) )
```

与跨度无关。零参数,承载全部跨日记忆。

### M3 Theta-y tracker

```
ŷ(k+h|k) = θ( u(k,h) ) · y_prev( u(k,h) )
```

`y_prev(s)` 是槽位 `s` 昨日的值。`θ(s)` 由标量 RLS 估计,先验 `θ₀ = 1`,此时退化为持续性。
每个槽位每天只更新一次。

### M4 T28 + AR(4) 迭代

残差自回归,系数冻结后递归:

```
r(k)      = y(k) - T_{k-1}( s(k) )
r̂(k+s|k)  = Σ_{j=1..p} φ_j · r̃(k+s-j)          s = 1..H
            其中 r̃ 在 s-j ≤ 0 时取真实残差,否则取自己的预测
ŷ(k+h|k)  = T( u(k,h) ) + r̂(k+h|k)
```

**这就是长期退化的机制**:`s > p` 之后每个输入都是预测值,递归按 `φ` 的谱半径衰减。
实测 `p = 4` 时它在 24 小时跨度上比裸模板还差 11.3%。

**阶数不是越大越好,而且 4 不是最优。** 120 天口径重测 p 从 1 到 48,工具是 `run_ar_order_sweep.m`:

| 跨度 | 最优 p | 该 p 的 RMSE | p = 4 的 RMSE |
|---|---|---|---|
| 5 分钟 | 3 | 10.478 | 10.568 |
| 30 分钟 | 5 | 16.752 | 16.820 |
| 1 小时 | 5 | 22.865 | 22.911 |
| 3 小时 | 2 | 37.960 | 38.107 |
| 6 小时 | 1 | 46.410 | 48.725 |
| 12 小时 | 1 | 49.132 | 54.201 |
| 24 小时 | 1 | 48.166 | 53.350 |
| **整图** | **1** | **46.834** | 50.830 |

**整图上从 p = 1 的 46.83 单调变差到 p = 48 的 67.24,一路没有第二个极小值。**
机制与上面的退化是同一条:阶数越高递归衰减越慢,长跨度上把当前残差水平外推得越远。
残差没有长期记忆,**快速衰减才是对的**。
短跨度上有一个很浅的最优,落在 p 等于 3 到 5 之间,改善只有 1% 量级。

**结论:M4 应该用 p = 1,整图改善 7.9%。**
即使换到 p = 1,M4 的 46.83 仍然打不过 M8 的 38.14。
**AR 残差是短跨度工具,不是主力。**

**这一条也推翻了归档脚本的前提。** 旧扫描用的是纯 AR 加常数水平,p 只到 10,也没钳位;
它的结论不能直接搬到模板加 AR 的结构上。

**实现上有一处提速。** 递推 `r̂(s) = φᵀ [r̂(s-1); ...; r̂(s-p)]`,把最新 p 个残差当作后向初始输出,
就等价于一个 AR(p) 滤波器,一次 `filter` 调用替代 288 次循环。
两式在随机系数上逐点一致,`p = 4` 时偏差 2.8e-17。48 个 p 值因此能在半小时内跑完。

### M5 Carry-forward

```
ŷ(k+h|k) = y(k)
```

与跨度无关。短跨度上极强,长跨度上等于随机游走。

### M6 T28 + DMS(4) 直接多步

每个跨度单独做一次最小二乘,不递归:

```
ŷ(k+h|k) = D_h · [ 1, r(k), r(k-1), ..., r(k-p+1) ]ᵀ + T( u(k,h) )
```

`D_h` 每日在滚窗上重估一次,窗长 `n_fit` 天。第 `h` 行的训练样本是 `{ r(j+h) 与 r(j..j-p+1) }`。

### M7 CF + DMS(4)

与 M6 同构,但回归量换成差分 `Δy`,基准换成 `y(k)`:

```
ŷ(k+h|k) = y(k) + D'_h · [ 1, Δy(k), ..., Δy(k-p+1) ]ᵀ
```

### M8 Anchor-mix

**当前单模型冠军。** 每个跨度独立最小二乘:

```
ŷ(k+h|k) = c_h + a_h · y(k) + b_h · T( u(k,h) )
           + Σ_{j=1..p} φ_hj · r(k-j+1)
           + Σ_{j=1..p} ψ_hj · Δy(k-j+1)
```

三个锚同时在场:最新价 `y(k)`、目标槽位的模板 `T`、以及短滞后修正。
系数每日重估,窗长 `n_fit` 天。

两个可选约束,代码里已实现但**调用时没打开**:

```
convex:   b_h = 1 - a_h,  a_h ← clip(a_h, 0, 1)
eta:      在滞后系数上加岭罚,权重取 mean(列能量) 的一个比例
```

参数名是 `convex` 与 `eta`,登记在 2.4。

**注意:现在跑的是无正则最小二乘,拟合时报秩亏(rank 10 对 12 列)。**

### M9 T28 + 水平偏置

```
L̂(d)     = c + b₁ · L(d-1)                       回归得到
L̂(d+1)   = c + b₁ · L̂(d)
ŷ(k+h|k) = T( u(k,h) ) + ( L̂(D) - L̄ )
```

`L(d−1)` 是原点的日之前最后一个**完整日**的均值。系数每日在滚窗上重估,窗长 `n_lvl` 天。
实测 `b₁` 的日均是 0.531。

### M10 Multi-window template

```
ŷ(k+h|k) = T_mw( u(k,h) )
```

与跨度无关。`W = {7, 28, 56, 112}`,四个窗口**等权**。

### M11 MW + 水平偏置

把 M9 的偏置加到 M10 上:

```
ŷ(k+h|k) = T_mw( u(k,h) ) + ( L̂(D) - mean_s T_mw(s) )
```

### M12 MW + 运行状态水平

M11 的改进版。偏置的当日部分换成运行均值:

```
ρ(k)      = ( 当日已观测槽位数 ) / n_s
L̂(D=当日) = ρ(k) · ( 当日运行均值 ) + ( 1 - ρ(k) ) · ( c + b₁ · L(d-1) )
L̂(D=次日) = c + b₁ · L̂(当日)
ŷ(k+h|k)  = T_mw( u(k,h) ) + ( L̂(D) - mean_s T_mw(s) )
```

**混合权重就是观测比例本身,不需要额外拟合。** 观测比例记作 `ρ(k)`,登记在 2.4。
这一条把 24 小时跨度的水平误差从 34.60 压到 7.62 至 26.36。

### M13 Kalman 谐波状态空间,已收编

`Kalman_predictor`。结构与其他模型完全不同。

```
状态      ξ_k = [ μ_k, α_{1,k}, β_{1,k}, ..., α_{J,k}, β_{J,k}, r_k, ..., r_{k-p+1} ]ᵀ
转移      ξ_k = A ξ_{k-1} + w_k,     w_k ~ N(0, Q_w)
观测      y(k) = C_k ξ_k + v_k,      v_k ~ N(0, R_v)
预言      ξ̂_{k|k-1} = A ξ̂_{k-1|k-1}
更新      ξ̂_{k|k}   = ξ̂_{k|k-1} + K_k ( y(k) - C_k ξ̂_{k|k-1} )
          K_k = P_{k|k-1} C_kᵀ ( C_k P_{k|k-1} C_kᵀ + R_v )^{-1}
H 步预测  ŷ(k+h|k) = C_{k+h} A^h ξ̂_{k|k}
```

符号见 2.9。`C_k` 由 `make_harmonic_C.m` 按目标槽位构造,含 `J = 3` 个谐波对。
`A` 由 `build_harmonic_ss_model.m` 构造,状态量是水平、各次谐波振幅、以及一个 `p = 4` 阶残差块。
谐波块有一条解析性质:`A^h` 的谐波部分是旋转 `h·ω_j` 角,所以 `A^{n_s}` 的谐波块是单位阵,
24 小时预测与当前相位自洽。这条性质在代码里被当作正确性自检。

**落到 288 乘 288 图集时的实现。** 照上式在每个原点跑 288 步,要构造 1000 万次观测行,跑不完。
观测行与状态无关,只有跨度与目标槽位决定它,于是可以预计算 `G(h,s) = C_s A^h` 这一张表:

```
ŷ(k+h|k) = G( h, u(k,h) ) · ξ̂_{k|k}
```

这张表全测试期共用,占 7 MB,预测退化成一次长度 `1 + 2J + p = 11` 的内积。
**这是等价变形,不改任何数值。判据:与逐点实现 `kalman_predict_288.m` 对比,
四个原点上的最大偏差是 5.1e-13。**

谐波基在热身期上拟合一次,滤波状态与协方差在线递推。
**这是"固定基"口径;谐波基每日滚动重估是另一个变体,尚未测。**

实测整图 44.73。**5 分钟跨度上 10.10,是全表最好的一个**,M8 在那里是 10.17。
到 24 小时是 48.76,退化得比 M8 快。**它是短跨度专家,不是全能选手。**

### M14 EWMA 模板,已收编

`EWMA_Template_predictor`。与 M2 同构,但窗口换成指数加权:

```
T_e(s) = Σ_{i=0..n-1} ω_i · y^{(i)}(s) / Σ_i ω_i,    ω_i = (1 - α)^i
```

`i = 0` 是最新一天,`α = 0.15`。历史严格截断在权重降到 `min_weight = 0.01` 的那一天,
所以缓冲深度是 `K = floor( log(min_weight) / log(1-α) ) = 28` 天。
**这一条是与归档版的区别:纯递归 `T ← (1-α)T + αy` 有无限记忆,本实现会真的丢掉旧数据。**

收编时**去掉了按星期几分型那一维**,分类单独由 M18 承担,两个方向分开测。

实测整图 42.99,**与 M10 多窗口模板撞到同一位小数**。
两者都是平滑模板,逐跨度上互有胜负:M10 在 5 分钟上 43.09 对 43.16,M14 在 24 小时上 42.66 对 42.75。
**结论:加权方式与窗口长度这两个方向,在整图上打平;要分胜负必须看第 5 节的差值图。**

### M15 至 M17 移动平均与移动中值,已收编

`Smoothing_predictor`。三个变体,窗口都是 12 点,即 1 小时:

```
不平滑补偿   ŷ(k+h|k) = S(k)
延迟补偿     ŷ(k+h|k) = S(k) + ( (w-1)/2 + h ) · ( S(k) - S(k-1) )
```

`S(k)` 是窗口内的均值或中值。**延迟 `(w-1)/2 = 5.5` 步是解析的,写在状态里,不靠调参。**

三个变体的整图:

| 模型 | 整图 | 24 小时 |
|---|---|---|
| M15 移动平均 | 51.51 | 48.30 |
| M17 移动中值 | 51.59 | 48.30 |
| M16 移动平均加延迟补偿 | 86.38 | 94.54 |

**三条结论,都是负面的,写清楚为什么不留:**

1. **平滑过的序列不是预测。** 移动平均的整图 51.51,比裸持续性 48.27 还差。
   它就是把当天已有的水平往后平推,没有任何跨日记忆。
2. **中值比均值略差,差得不多。** 51.59 对 51.51。钳位已经在处理尖峰,中值的稳健性在这里没有额外价值。
3. **延迟补偿是灾难。** 86.38,是全部 18 个模型里最差的,24 小时上 94.54 已经超过信号标准差 48.77。
   原因是把 1 小时的斜率线性外推 288 步,外推误差按跨度线性增长。

**判据:三条都以"整图更差"的形式成立,所以三个都不进组合。
保留在图集里是为了让"平滑后再预测"这个想法有一组可引用的数字,不是为了凑数。**
这一条同时回答了归档里那两种滤波器的去向。

### M18 按星期几分型模板,已收编

`Day_Class_predictor`。用目标日所属的类别取模板:

```
T_c(s) = ( 1 / N_c ) Σ_{d 属于 W_c} y_d(s),    c 属于 {工作日, 周末}
```

窗口与 M2 一样是 28 天,所以**分类是它与 M2 之间唯一的区别**,这是一个受控对比。

**实测 43.82,比同窗口不分型的 M2 的 49.12 好 10.8%。**
这**推翻了**旧协议下的那个结论。旧测量说"按星期几分型比不分型差 3.4%",
那是在训练 1 月、测试 7 天的口径下测的,样本太少,周末只有 2 天,分型反而把样本切碎了。
120 天口径下每个类别有 17 个周末日与 86 个工作日日,分型的收益才显出来。

**但 M18 仍然不是冠军。** 43.82 比不上 M10 多窗口的 42.99,更比不上 M8 的 38.14。
**正确的说法是:分类有价值,但不如把窗口长度做多。两个方向可以叠加,这留给第 6 节的组合。**

**这一条改进了报告的结论,不要再用旧的 3.4%。**

### M19 按跨度选 AR 阶数,第一版无效,要重做

动机来自 M4 的阶数扫描:最优阶数随跨度下降,30 分钟附近是 5,6 小时以上是 1。
把那张表直接用上不行,因为它是同一批 120 天上选出来的,等于用测试集调参。所以必须做成因果的。

```
候选集     P = {1, 2, 3, 5, 8}
每个候选一套独立的 RLS 状态
每个原点的候选预测   r̂_p = filter( 1, [1; -φ_p], 0, filtic(1, [1; -φ_p], r_hist(1:p)) )
跨度 h 的预测        ŷ(k+h|k) = T(u(k,h)) + r̂_{p*(h)}(h)
选择规则             p*(h) = argmin_p 过去最多 28 个完整日的平方误差
```

每个候选的 288 步预测是一次 `filter` 调用,所以五个候选几乎不增加成本。

**跑出来整图 49.27,比 M4 的 50.83 好,但比扫描给出的 p = 1 的 46.83 差。**
诊断把它暴露了:**在探针取的六个跨度上,规则 100% 选了 p = 1。**

**根因是选择用错了维度。** 累计的平方误差只按(目标槽位、候选、日)组织,**没有跨度这一维**,
所以 `min` 是在"对所有跨度求和"之后做的。它选出的是"每个目标槽位一个阶数",
不是"每个槽位与跨度各一个阶数"。聚合之后长跨度占主导,于是几乎全选 p = 1。

**这不是可以保留的近似,它没有回答原问题。要改的地方写清楚:**

1. 累计量改成(槽位、跨度、候选)三维,用按目标日的环形缓冲加滑动和,内存约 46 MB。
   不能直接存每天的全量,那是 288 乘 288 乘 120 乘 5。
2. 选择每天开始时做一次,窗口取最近 28 个完整目标日。落在窗口里的那天必须已经收齐,
   而目标日 `d-1` 的贡献在当天最后一个原点之前就全部到齐,所以窗口取到 `d-1` 是安全的。
3. 预测时按 `(u(h), h)` 取候选,不是只按 `h` 取。

**M19 现在这一列留在图集里只作中间结果,不要引用它的分数。**
下一次图集运行会把它换成正确的实现,同时修掉 PART 2 的稀释问题。

## 4. 跨度分层与各自的评价口径

**不同跨度是不同的题目,不能共用一套指标。**

| 层 | 跨度范围 | 分辨率 | 数据源 | 对照物 | 样本量 |
|---|---|---|---|---|---|
| **H1** | 0 至 1 小时 | 5 分钟 | 现有主序列 | AEMO P5MIN | 120 天,每格 120 |

### 4.1 各层的可达性,必须诚实写清

- **H1 与 H2 是本次真正做过的**,有 120 天、288 乘 288 的完整图集。
- **H3 可以重建,数据已补齐。** PD7DAY 有 2026-08-11 至 10-09 共 60 天、每天 3 次、180 个 run,最大跨度 183.0 小时。
  主序列原先只到 2026-08-09,现已补到 2026-10-13,`PRICE_AND_DEMAND_202608` 换成完整月并新增 `202609` 与 `202610`。
  **H3 窗口的 5 分钟实际价现在是完整的。**
- **H4 与 H5 没有官方对照物。**
  - 7 天以内还能用 STPASA 的 `DEMAND10/50/90` 与 `UIGF` 做外生变量,粒度 30 分钟,约 6 天。
  - **超过 6 天,连外生变量都没有。**
  - 1 个月以上的"预测"在本数据里只能验证**水平**(月均价、周均价),不能验证形状。
    这与 H1 至 H3 是不同的问题,评价指标要换成水平误差,不是逐点 RMSE。

**判据:第 4 节的每一层必须写明"对照物是什么",写不出对照物的层必须在报告里标成"只能自证",不得与 H1 至 H3 的数字并列。**

### 4.2 为什么必须分层

一个模型在 H1 赢、在 H2 输,是常态,不是矛盾。
实测:M4 在 5 分钟跨度 11.01,M12 是 32.96;到 24 小时 M4 是 54.39,M12 是 43.08。

**把 288 个跨度平均成一个数,会把这个交叉点完全抹掉。**
`run_predictor_suite.m` 已经犯过这个错,`run_full_ensemble_test.m` 里加了"整图"一列才看出来。

## 5. 图与表的规范

### 5.1 288 乘 288 热力图,什么时候够用

热力图 `R_m(s,h)` 的行是目标时刻、列是跨度、颜色是 RMSE。
**两个模型整图差距超过 15% 时,热力图一眼能看出差别。**
实测可以通过肉眼分辨的例子:M4 与 M12,`R̄` 是 50.83 对 39.83。

### 5.2 接近时的主图:差值图

**`R̄` 接近时不要并排放两张热力图,画一张差值图。**

```
Δ(s,h) = R_A(s,h) - R_B(s,h)
```

用**双向色图**(以 0 为白/中性的 diverging colormap),正负两端各一个色。
读法:哪一格是蓝的,就是 B 在那里更好;白色区域是两者打平。

实测接近的例子:M9 与 M11 在若干跨度上只差 1 至 2 $/MWh,并排热力图完全看不出,
差值图能直接指出差别集中在哪个时段、哪个跨度段。

**差值图必须配一个统一色标,并且报告 `max |Δ|`,否则读者不知道"深蓝"是差 1 还是差 20。**

### 5.3 分解:像傅里叶变换那样切

对任一模型的面 `R(s,h)`,做**双向方差分析恒等式分解**:

```
R(s,h) = R̄ + A_h + B_s + C_sh

R̄     = mean_{s,h} R(s,h)                         总水平
A_h   = mean_s R(s,h) - R̄                         跨度主效应,288 个值
B_s   = mean_h R(s,h) - R̄                         时段主效应,288 个值
C_sh  = R(s,h) - R̄ - A_h - B_s                    交互项
```

三个量的名字用大写,与 2.4 节 Anchor-mix 的小写系数 `a_h` `b_h` `c_h` 区分开,那是另一回事。

**交互项 `C_sh` 是"边缘剖面解释不掉的那部分",也是并排热力图看不出来的那部分。**

对差值面 `Δ(s,h)` 做**奇异值分解**:

```
Δ = Σ_i σ_i · u_i v_iᵀ

σ_i   第 i 个奇异值,差的幅度
v_i   跨度方向的特征剖面,长度 288
u_i   时段方向的特征剖面,长度 288
```

**这就是用户说的"像傅里叶变换一样"。** 首几个奇异向量告诉的是:
差别主要落在哪个**时段形状**与哪个**跨度形状**的组合上,以及每个组合占多少能量。
前 3 个奇异值占总能量的比例,就是一个"这个差别复杂不复杂"的度量:

- 前 1 个占 80% 以上:差别是单一模式,可以用一句话说清。
- 前 10 个才占 80%:差别是弥散的,说明两个模型本质接近,应当归入同一族。

### 5.4 切片纪律

**任何"某个模型在某个时段更好"的说法,必须过四关:**

1. **切片宽度。** 时段切片不得窄于 1 小时,跨度切片不得窄于 12 步。
2. **样本量。** 每个切片至少 30 天。少于 30 天不出结论。
3. **配对检验。** 用损失差序列 `E_A(s,h,d)² - E_B(s,h,d)²` 做 Diebold-Mariano 检验,
   零假设是两个模型预测精度相同。报告 `p` 值,不报告"看起来更好"。
4. **日度稳健性。** 报**日度胜率**而不是平均差:
   `P_d[ R_A(h,d) < R_B(h,d) ]`,其中 `R_x(h,d)` 是模型 `x` 在第 `d` 天跨度为 `h` 的 RMSE。
   胜率接近 50% 就说明差异是少数日子撑起来的。

**为什么必须有第 4 关**:单一一天的某个时段很容易被一个尖峰主导。
实测里 M4 在 5 分钟跨度上全场景最优,但它的整图比裸模板还差,就是因为长跨度上它系统性过冲。
只看任何单一跨度或单一天,都会得出相反结论。

### 5.5 显著性图

288 乘 288 有 82,944 个格子,逐格做检验会有大量假阳性。
用 Benjamini-Hochberg 在 5% 水平上控 FDR,然后画一张**三色图**:

```
红格    A 显著更好(FDR 校正后)
蓝格    B 显著更好
灰格    不显著
```

再报一个汇总数:**显著格数占全部格子的比例**。
这个数比任何一句"某模型更准"都硬。

### 5.6 三个实战样例

工具已经写成并跑通:`Predicitor\compare_surfaces.m`,驱动脚本 `Predicitor\run_surface_comparisons.m`。
三个样例都用 120 天图集,每个格子 120 个样本,82,944 个格子。

#### 样例一:差距明显的一对,M4 对 M12


1. 整图 A 更好 4.43%,但**差值在 84.0% 的格子上不显著**。
2. A 的显著优势**全部集中在 6 小时以内**,占 16.0% 的格子。

4. 差值谱 k=1 占 83.4%,说明差别是**单一模式**,可以用一句话说完:
   "A 用短跨度的巨大优势买下了整图,长跨度上两者没有差别。"

**如果只报整图,会得出"A 更好"的结论,而这个结论在 12 小时跨度上是错的。**
这正是切片纪律存在的理由。

#### 样例三:最干净的一对,M9 对 M11,同一个想法换窗口

```

```

**这是三条纪律的最佳示范:**

1. **差值面的最大绝对值只有 23.35,而方差份额里时段占 93.1%。**
   意思是这个改进**几乎纯粹是一个日内时段的形状改进**,与跨度基本无关。
2. **差值谱 k=1 占 99.9%。** 差别是**一个**模式,不是十个。
   按 5.3 的判据,这属于"可以用一句话说清"。
3. **日度胜率在每个跨度上都是 85.0%。** 这是最硬的一条:
   不是某一天赢,也不是某个时段赢,而是**120 天里 85 天赢,且与跨度无关**。

**一句话结论:多窗口模板比单窗口模板好在日内的某些时段,好在一个固定的形状上,并且在 85% 的日子里稳定复现。**

   best-2 是 38.60,best-3 是 39.05,best-5 是 39.34,**三个都不如 36.93 的全等权**。
   这条推翻了之前的结论。之前那三个数字是 33.01 与 33.06,看着比全等权好,
   原因是它们有两处高估:选模型时用了被评分当天自己的误差,以及前 28 天的空格把 RMSE 稀释了 12.4%。
   **两处都修掉之后,挑模型的规则输给了不挑。**
3. **收缩是有效的。** 同一个 4 小时分块,收缩 0.3 把它从 37.38 拉到 36.30,改善 2.9%。
   误差协方差在 28 天窗口上估计得不好,向对角收缩压掉了那部分估计噪声。

**为什么之前会高估,记在附录 B 里,两条都别再犯。**

### 6.2 四种组合规则的严格定义

**规则一,固定等权。** `w_m = 1/|S|`,`S` 是选定的子集。零调参。

**规则二,因果选择性等权。** 对每个跨度 `h` 与每一天 `d`:

```
取窗口内每个模型的 RMSE: ρ_m(h,d) = sqrt( mean_{d' 属于 [d-n_w, d-1]} mean_s E(s,h,d',m)² )
排序取最小的 K 个,记作 S_K(h,d)
w_m = 1/K   若 m 属于 S_K(h,d),否则 0
```

**规则三,因果最优权重。** 对每个跨度块 `b` 与每一天 `d`,解约束最小二乘:

```
S_b,d = (1 / n) Σ_{样本} e_b,d e_b,dᵀ                     误差协方差,按跨度块
S_b,d ← ( 1 - ε ) S_b,d + ε ( trace(S_b,d) / M ) I        收缩到对角
w = S_b,d^{-1} 1 / ( 1ᵀ S_b,d^{-1} 1 )                     Σ w = 1 的闭式解
```

**规则四,两模型混合。** 规则三在 `M = 2` 时的特例,方差最小,短跨度上实测最好。

### 6.3 集成层已经落成的样子

`Predicitor\Ensemble_predictor\` 四个函数,全部已实现,并由 `run_ensemble_online_test.m` 按天驱动验证过。

```
st = init_ensemble( n_models, n_s, n_w, 'K_sel', 0, 'eps', 0.3, 'B', 48 )
st = update_ensemble( st, day, E_day )
[w_sel, w_opt, info] = combine_ensemble( st, h, mode )      mode 取 "sel" / "opt" / "both"
y_hat = predict_ensemble( F, W )
```

**它存误差,不存预测。** 因为凸组合满足 `e_c = Σ_m w_m e_m`,拿到各子模型的误差就能直接算出组合误差,
不必让每个子模型再跑一遍。这让同一套引擎既能在实机上用,也能在存好的图集上复算并互相对账。

| 函数 | 契约 |
|---|---|
| `init_ensemble` | `n_w` 天后开始有权重。缓冲区是 `n_s × n_s × n_w × n_models` 的环形缓冲 |
| `update_ensemble` | 吃进一个完整日的误差块 `E_day`,尺寸 `n_s × n_s × n_models`。第 `d` 日的块在第 `d+1` 日第一个控制步之前就到齐了,所以没有前视 |
| `combine_ensemble` | 规则二**逐跨度**选模型,输出 `n_s × n_models` 的整日权重表;规则三**逐跨度块**拟合协方差,输出 `n_models × 1` |
| `predict_ensemble` | `W` 是列向量就施加到所有点;是 `n_point × n_models` 就逐点用各自的权重行 |

**为什么规则二逐跨度、规则三逐块:** 规则二只做排序,288 个跨度各自排序很便宜;
规则三每个跨度要解一次 19 乘 19 的方程组,逐跨度做就是每天 288 次求解,没有必要。

**判据(第 9 节第 12 条):** 与 `run_ensemble_combos.m` 的离线结果差在 0.1 $/MWh 以内。
**参照值从 `combos.mat` 里读,不写死在驱动脚本里**,这样两个脚本是真的在互相对账,而不是把一个抄进另一个。

**还没做的部分。** 上面这套是组合层,它不管子模型的状态。要在实机上跑,还需要一个把 19 个子模型的状态
收在一个结构体里的编排层。**建议单独做一步**,因为其中 8 个模型(M1 M2 M4 M5 M6 M7 M8 M19)共用同一份
模板与残差历史,必须先抽成一个模块,再逐个搬其余的。那一步同样要用"图集逐位一致"做判据。

### 6.4 验证协议

1. **样本外。** 权重只能用目标日之前的数据。
   **这一条原先在 `run_ensemble_combos.m` 里是假的**,规则二用到了被评分当天自己的误差,见附录 B。
   现在已经改成取 `d-1` 处的窗口。
2. **同一天数比较。** 因果规则天然有前 `n_w` 天没有权重。**不能拿它和写满全期的规则直接比**,
   也不能让那 `n_w` 天的零参与 pooled RMSE。所有规则一律在第 29 天到第 120 天上评分。
3. **滚动前向。** 不能只做一次 120 天固定回测。至少切成 4 段,逐段报告。
4. **对照物三选一。** 最好的单模型、等权全模型、AEMO 官方预测。
5. **报告四件事:** 整图 `R̄`、日度胜率、显著格数占比、SVD 首分量占比。

**判据:集成模型必须在 4 个分段里都赢过最好的单模型,否则说明它只是在某一段的行情里占便宜。**

## 7. EMPC 集成

### 7.1 接口

MPC 层每个控制步需要一条未来 24 小时的价预测。定义:

| 项 | 值 |
|---|---|
| 调用时刻 | 每个 5 分钟边界 |
| 输入 | 当前槽位 `s(k)`,最近观测 `y(k)` |
| 输出 | `ŷ(k+1..k+288)` 长度 288 的价向量,单位 $/MWh |
| 可选输出 | 分位数 `ŷ^{0.1} ŷ^{0.5} ŷ^{0.9}`,用于鲁棒 MPC |
| 延迟 | 必须小于 5 分钟,含全部子模型更新 |

**第 288 步的预测是否可信,直接决定 MPC 的最后一步调度。**
实测最好的组合在 24 小时跨度上是 36.34,而全天信号标准差是 48.77。
**这个比值决定了 MPC 能用多长的滚动视野。**

### 7.2 与 AEMO 官方预测的比对

三条基线,逐条比:

1. **AEMO P5MIN**,1 小时以内,5 分钟粒度。
2. **AEMO PREDISPATCHIS**,40 小时以内,30 分钟粒度。要比到 30 分钟口径需先把 5 分钟预测聚成 30 分钟。
3. **AEMO 官方预测加我们的修正**,即把官方预测当基准,我们只预测它的误差。

**第 3 条是最有希望的方向**:官方掌握机组停运、网络约束、联络线潮流,这些我们永远看不到。
正面比赢它不现实,但它的误差是强自相关的,可以修。

`Weekly\EMPC\2026-09-23` 的实测已经给出这个方向的证据:
P5 的误差 ACF 在 lag 1 是 0.50,同号连续段平均长度 6.15 个区间,最长 122。
**误差成串出现,意味着可预测。**

### 7.3 EMPC 的评价指标

不能只看预测的 RMSE。要报三个:

| 指标 | 定义 | 为什么 |
|---|---|---|
| 预测 RMSE | 已有 | 上游质量 |
| 闭环电费 | EMPC 调度下的实际电费 | 真正关心的 |
| 与完美预测的电费差 | 用真实价格重跑 MPC 得到的电费作为下界 | 衡量预测误差值多少钱 |

**判据:一个预测器即使 RMSE 更好,如果闭环电费没有改善,就不能算改进。**

### 7.4 刷新节奏:控制器多久更新一次价预测

工具 `Predicitor\run_update_cadence_sweep.m`,数据 `cadence_sweep.mat`,图 `cadence_sweep.png`。

口径:每一次刷新发出一整条 288 步向量,两次刷新之间控制器继续用旧的那一条。
于是每个目标点用的是"最近一次刷新"发的那条,有效跨度 `eff = mod(jj-1, K) + 1`,落在 1 到 K 之间。
**这个扫描不需要重新流一遍数据**:图集里已经存了每个原点每个跨度的误差,这是一次重索引。
判据:`K = 1` 必须复现图集的第 1 跨度整列,实测偏差 **0.000e+00**。

**一条必须先写清的方法学限制。** 固定周期下有效跨度与目标槽位是绑死的:
`eff = mod(jj-1, K) + 1`,而 `slot = mod(jj-1, n_s) + 1`,所以一次扫描只走一条对角线,不是整张面。
因此 **K 取 `n_s` 时不等于整图 RMSE**,而是"槽位等于跨度"那条对角线上的 RMSE,两者差 9.1 $/MWh。
要让不同节奏可比,只能把每条节奏限制到它自己那组刷新原点上,
再与"同一组原点、每步刷新"作对照。

冠军 M8 的代价,同一组原点上的对照:

| 刷新间隔 | 每步刷新 | 每 K 步刷新 | 代价 |
|---|---|---|---|
| 5 分钟 | 10.169 | 10.169 | — |
| 30 分钟 | 9.847 | 12.860 | +30.6% |
| 1 小时 | 9.624 | 15.548 | +61.6% |
| 6 小时 | 9.439 | 28.654 | +203.6% |
| 24 小时 | 8.505 | 37.436 | +340.2% |

**每步刷新那一列几乎不变**,说明这五组原点的难度是稳定的,所以右边那一列代价是可比的。

**第二条结论:不同模型对节奏的敏感度差得很远。**

| 模型 | 5 分钟 | 24 小时 | 退化倍数 |
|---|---|---|---|
| Kalman 谐波 M13 | 10.10 | 43.23 | 4.3 |
| T28 + AR4 M4 | 11.01 | 43.77 | 4.0 |
| Anchor-mix M8 | 10.17 | 37.44 | 3.7 |
| 18 个等权 | 21.44 | 36.00 | 1.7 |
| Multi-window T M10 | 43.09 | 42.75 | 1.0 |

**模板类模型几乎不随节奏退化,短跨度专家退化三四倍。**
**18 个等权在 24 小时上是 36.00,反而比冠军 M8 的 37.44 更好**:
组合里有不随节奏退化的成员,把短跨度成员的退化摊平了。

**给 MPC 的结论:要降低刷新频率,就必须把权重往模板类倾斜,不能继续用短跨度最优的那套权重。**
**这一条把第 6 节的"混合方式必须随跨度变"扩展成"也必须随刷新节奏变"。**

## 10. 风险与已知的坑

| 坑 | 现象 | 处理 |
|---|---|---|
| MATLAB MCP 超时打断脚本 | 调用 4 分钟超时,MATLAB 回到空闲,diary 是 0 字节 | **一律用独立进程跑** |
| 跨脚本数字对不上 | 同一个模型在两个脚本里差 8 个点 | **必须对账**。靠这条已经抓到五个 bug |
| 图集占内存 | 18 个模型在内存里是 716 MB,存盘 427 MB | 只保留当前在用的一个。`atlas_full.mat` 与 `atlas_ext.mat` 并存占 710 MB |
| 秩亏 | Anchor-mix 拟合每天报一次 rank 10 对 12,120 天就是 288 条警告 | 参数名是 `eta` 不是 `shrink`。打开它可以同时消掉警告与秩亏,但**必须重跑一次验证整图没变** |
| 逐列读 v7.3 文件 | 一列 40 MB 要读约 70 秒,18 列读两遍就是 40 分钟 | **整体 `load` 一次**,一分钟解决。别用 `matfile` 逐列取 |
| 刷新节奏与槽位锁死 | K 取 `n_s` 时算出的 RMSE 与整图差 9.1,看着像索引写错 | 这是真实现象不是 bug。固定节奏下有效跨度与目标槽位被绑在一条对角线上,见 7.4 节 |
| 别种语言的语法混进来 | `for x in [...]` 报 `Parse error at in` | 改完 MATLAB 脚本**先跑一次静态分析**,这一类错它全查得出 |
| 单一窗口偏差 | 只看某一天或某个时段会得出相反结论 | 5.4 的四关 |
| 归档件混进在役路径 | `addpath(genpath(Predicitor))` 会把 archive 也挂上 | 新入口一律用显式 `addpath` |
| NEM 时间与本地时间 | 本机是 UTC+11,数据是 UTC+10 | 一切按 NEM 时间,不让 MATLAB 做时区换算 |
| 钳位口径混用 | 状态在原始价训练,评分在钳位价 | 每次写新模块都要确认这条 |
| 模型登记表与脚本脱节 | 登记表里加了模型,脚本里没写对应的预测规则 | 图集脚本的 `switch` 有 `otherwise` 分支,会直接报错而不是静默填零 |

**十六条里有十三条是"数字对不上"或"判据过不去"发现的,不是读代码发现的。**
检验符号写反那条尤其典型:两个统计量互相矛盾,一定有一个错。
**稀释那条更值得记:同一条错误让三个组合分数一起偏低了 12.4%,而它们互相之间对得上,
所以只有拿它们和"没有稀释的那一行"比才会露馅。**
所以第 9 节的每一条判据都要求跨脚本、跨统计量对账。

**本轮新增的四条判据就是从这些错误里长出来的:**
1. `run_full_ensemble_test.m` 的整图最优权重必须与 `run_ensemble_combos.m` 逐位一致,否则说明两个副本又分叉了。
2. Kalman 的预计算表必须与逐点实现在机器精度上一致,两条独立实现互相对账。
3. `run_ar_order_sweep.m` 里 `p = 4` 必须复现图集的 T28 + AR4 那一列,复现不了就说明扫描的协议与图集漂移了。
4. **所有组合规则必须在同一段日期上评分。** 因果规则天然有前 `n_w` 天没有权重,
   不能拿它和写满全期的规则直接比,也不能让空格参与 pooled RMSE。
