## 三种版式与实测宽度

页面区仍是 `TOP = 1.38` 到 `FIG_BOTTOM = 6.60`,预算 5.22 英寸。图的宽高比决定用哪一种:

| 版式 | 触发条件 | 实际用的宽度 |
|---|---|---|
| 图左说明右 | 宽高比小于 3 | 从 8.60 起逐档降到装得下;f3 用 8.00,其余 8.60 |
| 图上说明下 | 宽高比大于等于 3 | 从 11.00 起降;f2c 用 8.60,f6 与 f9 用 9.00,f8 用 10.20 |
| 纯两栏说明 | 结构页与索引页 | 两栏各 5.95 |

**递减阶梯是必须的。** f3 的宽高比是 1.588,按 8.60 宽度算出来 5.42 英寸,直接压进口径带;降到 8.00 正好 5.04。所以求解器不许只试一个宽度。

## 新增的坑

| 坑 | 后果 | 处理 |
|---|---|---|
| **MATLAB 里 `struct()` 传 `cellstr` 会构造结构体数组** | 写成 `struct('lag', 5, 'ac', row, 'names', cellstr(names))` 得到 1×16 的结构体数组,下一句 `out.banding.identical_pairs = ...` 报 "Scalar structure required",整轮取数白跑 | 用 `{cellstr(names(:))'}` 把名字包成**字段值**;或干脆建结构体数组再整体塞进外层字段 |
| **同一个 `struct()` 的字段长度必须一致** | `num2cell(band.ac)` 是 1×16、`cellstr(names)` 是 16×1,报 "Array dimensions of input '6' must match those of input '4'" | 转置成同一形状 |
| **变量前向引用** | 新块用了后面才定义的 `mt`,报 "Unrecognized function or variable" | 就地写 `find(keys == "T28", 1)`,不跨块借变量 |
| **图上的读数不能凭记忆写** | 我按交接报告的印象写了"锚定模型在第一小时赢",实际六个固定跨度上 288 时段的中位数**全是官方最低** | 逐列取了 `median_by_lead` 与各模型 `med32` 对比后才落笔 |
