## 1 评价口径,三条硬规矩

**一、预测误差只能在二维面上比较。** 两个维度是预测的时刻与预测的提前量。**整图 RMSE 任何情况下都不作判据**,只在确认一次改动没动到别处时当指纹用。

**二、合法对象只有四样。** 整张二维误差面;固定提前量下那 288 个时刻的剖面;固定时刻下那 376 个提前量的剖面;以及对整张面做一次逐格计数。

**三、逐格计数也不是结论。** 它把"在哪些格子上赢"压掉了。实例:推荐的组合在 86.5% 的格子上更低(那是 24 小时轴),可按跨度拆开,5 分钟跨度上 288 个时刻里只赢 13 个。

**只有相对比较,没有绝对比较。** 任何"某模型最好"的句子必须带上它是哪一维、取哪个切片。

配套判据:逐格配对 Diebold-Mariano,Newey-West 滞后 7 阶,Benjamini-Hochberg 控 5% 错误发现率。**判定图不表示差别有多大**,它回答"差别稳不稳"。

**图与结论必须成对。只给数字不给图视为没有结论。**

相关技能:元层 `forecast-eval` 域,12 条规则,讲的就是本项目的评价口径。

## 4 已确认的结论

完整表在 `HANDOVER_60天7日图集_数据与结论_20261014.md`。摘要:

**一、长轴上换了一批赢家。** Anchor-mix 从 24 小时轴上的 46.68% 掉到 6.41%,裸模板 T28 与按星期几分型的 T28 各自拿走 15.1% 与 13.6%(含官方竞争时是 17.5% 与 19.8%)。含当前价的模型在长档全部失效:7.6 天那一端 Carry-forward 与 CF+DMS4 退化到 70.1,裸持续性 58.1,而 Template T28 是 41.9。

**二、官方在 7.6 天轴上是最强的单个候选**,逐格普查占 **21.77%**,但不过半。

**三、逐格看,十个模型净胜官方,五个净输,M4 平手。** 净胜的是 M2、M6、M8、M9、M10、M11、M12、M14、M18、M20;净输的是 M1、M3、M5、M7、M13。分母是 **101,280 个可比格**。

**四、融合在长轴上失效。** 24 小时轴上 86.5% 更低的推荐规则,在 7.6 天轴上是 54,208 比 54,080,抛硬币。

**五、逐格选阶是长轴上的正面结论。** `T28 + AR(n per cell)` 对 `T28 + AR4`:91,861 格更低,16,400 格更高,中位差 −5.586 $/MWh。

**六、6 小时以内难分伯仲。** Anchor-mix、T28 + AR(n per cell)、T28 + DMS4、T28 + AR4 与"all others"各占一块。**过了 6 小时只剩 Template T28 与 Weekday-class T 两分天下。**

**七、24 小时到 4 天之间分时段。** 18:05 至次日 06:05 是 Weekday-class T 占优,06:05 至 18:05 是 Template T28 占优。

**八、横向带状结构是网格的固有性质,不是噪声。** 过了第一小时一列是 30 分钟,所以 **48 列正好是一天**。锚在原点上的模型(M1、M3、M5、M7、M13)其误差取决于原点钟点与原点的日,两者都以 48 列为周期。判据:T28 的 `R` 在 375 个相邻列对里 **368 对逐位相同**,剩余 7 处全部落在 24 小时整数倍上;lag-48 自相关 T28 0.998、carry-forward 0.781、kalman 0.675。**这一条是 PPT 上必须解释的,不然图一看起来像有伪影。**

## 7 已知的坑,别再犯

| 坑 | 后果 |
|---|---|
| **日志名沿用** | 旧进程握句柄,删除与新重定向静默失败,读到上一轮输出 |
| **`sum(sum(X))` 对三维仍返回向量** | `fprintf` 把格式跑 60 到 376 遍。三维一律 `sum(X,'all')`,打印前断言标量。**本轮第三次犯** |
| **`mean(A,'omitnan')` 不带维度** | 沿第一非单例维求,返回向量不是标量 |
| **`["a" "b"]` 是字符串数组不是拼接** | `sprintf` 报 vertcat;拼接要用 `+` |
| **`strings(size(rowvec))` 是行向量** | 与标量竖接失败;要显式建成列向量 |
| **`n_s` 与 `n_h` 混用** | 288 轴上两者相等,错也看不出来;376 轴上才炸。**回归对照抓不到这一类** |
| **`model_index` 返回全量 registry 下标** | 过滤模型后组合规则会读错列;应用 `col_of`,匹配不到直接报错 |
| **`E4` 初值 0 不是 NaN** | 未填充格读作零误差,占 6.20%;要用"全模型为 0"识别 |
| **`cell_dm` 天数口径与 `R` 不一致** | 官方缺一天就让整格判成不可分辨,可分辨格数被压掉 93% |
| **单精度容差** | 立方存 single,在 23200 $/MWh 上一个 ULP 是 0.002,判据不能用 1e-6 |
| **PD7DAY 发布间隔** | 隔夜是 13.5 小时,不是 11.5 |
| **跨午夜的日索引** | 槽位在午夜折叠,从槽位推不出日 |
| **`fit_anchor_mix` 参数块与签名不一致** | MATLAB 直接拒绝运行(这是正确的) |
| **`R_cand` 按步数索引** | 不是按列号,要过一次 `h_all` |
| **图标题里塞口径** | 用户要求标题不要动 |

**通则一:输入相同而输出不同时,不要继续查输入,去查那个函数本身,用一个不经过它的实现来对照。**

**通则二:一个模型在整张面上给出同一个值,这个形状本身就可疑,通常是比较退化了。**

**通则三:在一根轴上两个量恰好相等的地方,任何"混用"都测不出来。回归对照只能证明共有的部分没变,证明不了新轴上的部分是对的。**
